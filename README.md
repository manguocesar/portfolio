## <a name="tech-stack">⚙️ Tech Stack</a>

- Typescript 5

- Tanstack Query 5
- React Three Fiber 9
- Framer Motion 12
- NEXT PWA 5

## <a name="quick-start">⚙️ Quick Start</a>

1.  **Install the dependencies.**
    ```shell
    pnpm
    ```

2.  **Run the app locally.**
    ```shell
    pnpm run dev
    ```
Open the browser at http://localhost:3000/
