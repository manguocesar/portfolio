## ⚙️ <a name="introduction">Introduction</a>

Portfolio Next app to showcase freelance projects & web development skills.

## ⚙️ <a name="tech-stack">Tech Stack</a>

- Next.js 15 app router
- TypeScript 5
- Tailwind CSS 4
- Tanstack Query 5
- React Three Fiber 9
- Framer Motion 12
- NEXT PWA 5

## ⚙️ <a name="quick-start">Quick Start</a>

1. **Install the dependencies.**

    ```shell
    pnpm install
    ```

2. **Run the app locally.**

    ```shell
    pnpm run dev
    ```

    Open the browser at [http://localhost:3000/](http://localhost:3000/)
